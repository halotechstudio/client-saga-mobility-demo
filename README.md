# SAGA Mobility · design demo

Rider app, driver app and ops command centre for SAGA Mobility, Visakhapatnam. All figures are sample data.

- `index.html`: opens the v2 app suite (`v2/`)
- `v1.html`: previous concept, all three v1 apps on one screen
- `saga-app.html`: rider app with the SAGA Saathi voice demo
- `saga-driver.html`: driver app
- `saga-ops.html#command`: ops console and AI command centre
- `saga-brand-manual.html`: brand manual
- `v2/`: app suite v2 (rider for iPhone and Android, chauffeur, hotels, ops, screen map, client brief)
